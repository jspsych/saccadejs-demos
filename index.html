SaccadeJS demos

The three experiments behind the SaccadeJS paper, as participants ran them. None of them saves or sends any data. They need a webcam, a keyboard and a desktop browser (Chrome, Edge or Firefox).

Training data collection

The task that recorded the training set (June 2023 to April 2024): 144 targets on a 16 × 9 grid, with a short webcam clip at each one and an occasional color change to catch with the spacebar. About 10 minutes.

Full task Short version

Held-out data collection

The same task run twice over, 288 targets, which recorded the held-out evaluation set (December 2024 and March 2025). About 15 minutes.

Full task Short version

Validation study

The study that compared SaccadeJS with WebGazer (September 2026, version 1.4.1). It downloads the SaccadeJS model (about 20 MB) and runs it in your browser, then records what each tracker would need to predict gaze while you follow targets. About 10 minutes.
